# 🌐 Rajmani Sharma | Portfolio Website

A personal, responsive portfolio website built using **HTML**, **CSS**, and **JavaScript** to showcase skills, projects, and contact details. It features a modern glassmorphism design, smooth UX, and clean navigation.

---

## ✨ Features

- 🔥 Responsive and elegant design  
- 💻 Project showcase with styled cards  
- 🧑‍💻 About section with developer profile  
- 📬 Contact area with interactive email reveal  

---

## 🛠️ Technologies Used

- **HTML5** – structure  
- **CSS3** – visual styling  
- **JavaScript** – interactivity  
- **Google Fonts** – custom typography
